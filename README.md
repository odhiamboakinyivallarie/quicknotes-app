# QuickNotes

QuickNotes is a simple note-taking web application that allows users to create, organize, search, and delete notes by category.

## Features

- Create notes with Personal, Work, or Study categories.
- Search notes by text.
- Delete individual notes.
- Validate empty notes and limit notes to 200 characters.
- Display the total number of notes.
- Save notes in browser local storage so they remain after refreshing the page.
- Responsive layout for smaller screens.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## How to Run the App

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser, or use the VS Code Live Server extension.

No additional installation is required.
